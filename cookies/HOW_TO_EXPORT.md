# How to export cookies

1. Install Chrome extension: **EditThisCookie** or **Cookie-Editor**
2. Log into LinkedIn / Indeed / Naukri in Chrome
3. Open the extension → Export as JSON
4. Save to this directory:
   - `linkedin.json`
   - `indeed.json`
   - `naukri.json`

Cookies expire — re-export if agent hits login walls.
